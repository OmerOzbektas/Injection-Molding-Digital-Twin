# Dataset access

Download **ExperimentalData.zip** from the [RWTH Aachen publication record](https://publications.rwth-aachen.de/record/1016199) using a normal web browser. The publications server may present an anti-bot HTML challenge when accessed with `requests` or `wget`.

Keep the original ZIP in the notebook working directory, or upload it using the first Colab cell. The data are not included in this repository.

The archive's README describes the data under **Creative Commons Attribution–NonCommercial 4.0 International (CC BY-NC 4.0)**. That license applies to the source data; it is **not** a general license granted by this project for the author's analysis code. Attribute the original RWTH researchers and respect the noncommercial terms when using or distributing the experimental data.

Required files live inside the ZIP under `figures/figure10/` and `figures/figure8/`. Do not extract the ZIP unless you prefer to; the notebook reads directly from it.
